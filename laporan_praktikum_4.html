BAB I: TUJUAN PRAKTIKUM

Praktikum Modul 4 Pemrograman Web ini dirancang guna membekali mahasiswa dengan penguasaan fundamental dalam menata antarmuka halaman web secara sistematis dan terstruktur. Adapun tujuan capaian pembelajaran praktikum ini adalah:

  1. Memahami Struktur Dasar Pembuatan Web Layout: Mampu merancang kerangka penempatan elemen antarmuka (header, navigasi, hero banner, area konten utama, sidebar widget, dan footer).

  5. Menerapkan HTML5 Semantics Elements: Menggunakan elemen semantik baku (<header>, <nav>, <section>, <article>, <aside>, <footer>) untuk kode yang terstruktur, mudah dirawat, ramah SEO, dan berstandar aksesibilitas tinggi.

BAB II: LANDASAN TEORI

1. Web Layout

Web Layout merupakan rancangan penataan tata letak komponen grafis dan teks pada layar browser. Layout yang proporsional berfungsi memudahkan pengunjung dalam mencerna alur informasi, menyederhanakan navigasi, serta meningkatkan estetika dan kenyamanan pengalaman pengguna (*User Experience*).

2. Box Element (CSS Box Model)

Dalam paradigma peramban web modern, seluruh elemen HTML direpresentasikan sebagai sebuah kotak persegi panjang (*box*). CSS Box Model tersusun atas empat lapisan konsentris:

  • Content: Area inti tempat teks, gambar, atau media disajikan.
  • Padding: Ruang transparan di sekeliling konten di dalam border.
  • Border: Garis pembatas fisik yang mengelilingi padding dan konten.
  • Margin: Ruang pemisah transparan di luar border yang memisahkan elemen dari elemen tetangganya.
MARGIN (Area Ruang Terluar)
BORDER (Garis Batas Elemen)
PADDING (Bantalan Ruang Dalam)
CONTENT (Isi Teks / Gambar)
Gambar 2.1: Visualisasi Konseptual CSS Box Model
Catatan Penting: Deklarasi box-sizing: border-box; memastikan bahwa penambahan padding dan border tidak akan memperbesar lebar total elemen yang telah ditetapkan, sehingga perhitungan layout multi-kolom menjadi presisi.

3. CSS Float Property & Clearfix Technique

Properti CSS float mengangkat elemen dari aliran normal dokumen (*normal document flow*) dan menggesernya ke sisi kiri atau kanan wadah induknya. Ketika seluruh elemen anak (*child elements*) menggunakan float, elemen pembungkus (*parent container*) akan kehilangan perhitungan tinggi fisiknya, suatu fenomena yang dikenal sebagai Height Collapse.

Untuk menormalkan kembali aliran dokumen, digunakan properti clear atau teknik Clearfix Modern:

CSS: Standar Modern Clearfix
.row::after,
#wrapper::after {
    content: "";
    display: table;
    clear: both;
}

4. HTML5 Semantic Elements

Standar HTML5 memperkenalkan elemen-elemen yang memiliki arti semantik eksplisit bagi peramban dan mesin pencari, menggantikan ketergantungan pada generic div (*div soup*):

Elemen Semantik Peran Struktural & Fungsi
<header> Mendefinisikan bagian kepala dokumen, judul situs, logo, dan sub-judul.
<nav> Membungkus menu navigasi utama situs atau tautan internal halaman.
<section> Mengelompokkan babak konten mandiri bertema tertentu.
<article> Menyajikan konten independen yang dapat disindikasikan (artikel berita, postingan blog).
<aside> Mendefinisikan bilah samping (*sidebar*) untuk widget, daftar link, atau kutipan pendukung.
<footer> Menyajikan bagian kaki halaman (hak cipta, info kontak, disclaimer).

BAB III: LANGKAH-LANGKAH PRAKTIKUM (BAGIAN 1)

Langkah 1 Box Element Dasar Tanpa Float

Pada tahap pertama, dibuat tiga buah tag <div> (Div 1, Div 2, Div 3) dengan warna latar berbeda. Karena elemen <div> merupakan elemen bertipe block-level secara default, setiap elemen mengambil 100% lebar yang tersedia dan tersusun secara vertikal dari atas ke bawah.

Kode HTML & CSS: Box Tanpa Float
<style>
    div { padding: 10px; }
    .div1 { background: red; }
    .div2 { background: yellow; }
    .div3 { background: green; }
</style>
<section>
    <div class="div1">Div 1</div>
    <div class="div2">Div 2</div>
    <div class="div3">Div 3</div>
</section>
Gambar 3.1: Tampilan Tiga Box Element Default Tanpa Float (Tersusun Vertikal)
Langkah 2 Penerapan CSS Float Property

Menambahkan deklarasi float: left; pada selector div. Hal ini melepaskan elemen dari aliran baris normal dan menjejerkannya secara horizontal ke arah kiri secara bersebelahan.

Kode CSS: Box dengan Float Left
div {
    float: left;
    padding: 10px;
}
.div1 { background: red; }
.div2 { background: yellow; }
.div3 { background: green; }

BAB III: LANGKAH-LANGKAH PRAKTIKUM (BAGIAN 2)

Langkah 3 Penerapan Clearfix pada Div 4

Ketika ditambahkan elemen keempat (<div class="div4">Div 4</div>), tanpa aturan clear elemen tersebut akan tetap mengalir di samping elemen float sebelumnya. Dengan menerapkan clear: left; float: none;, Div 4 dipaksa turun ke baris baru tepat di bawah elemen-elemen float.

Kode CSS & HTML: Clearfix Div 4
<div class="div4">Div 4</div>
/* CSS */
.div4 {
    background-color: blue;
    clear: left;
    float: none;
    color: white;
}
Gambar 3.3: Tampilan Div 4 yang Turun ke Baris Baru Menggunakan Clear: Left
Langkah 4 Eksperimen Properti Clear (left, right, both)

Eksperimen modul halaman 5 membuktikan bahwa clear: both; menjamin elemen berada di bawah semua elemen float baik dari sisi kiri maupun kanan. Pada pengujian ini, Div 2 diberi float: right; sementara Div 1 & 3 diberi float: left;. Deklarasi clear: both; pada Div 4 secara sempurna membersihkan kedua sisi.

Kode CSS: Eksperimen Clear Both
.div1 { background: red; float: left; }
.div2 { background: yellow; float: right; }
.div3 { background: green; float: left; }
.div4 {
    background-color: blue;
    clear: both;
    float: none;
    color: white;
}
Gambar 3.4: Eksperimen Clear: Both Menurunkan Div 4 di Bawah Float Left dan Float Right

BAB VI: KESIMPULAN & PENGESAHAN

Kesimpulan Praktikum

Berdasarkan seluruh rangkaian praktikum dan penyelesaian tugas mandiri yang telah dilaksanakan pada Modul 4 CSS Layout, dapat ditarik kesimpulan komprehensif sebagai berikut:

  1. Struktur Tata Letak Web: Penerapan kerangka layout yang terencana dengan pembagian header, menu navigasi, hero banner, main content, sidebar widget, dan footer menciptakan struktur web yang ergonomis, intuitif, dan nyaman dijelajahi oleh pengguna.
  2. Penguasaan CSS Box Model: Pemahaman mendalam mengenai komponen content, padding, border, dan margin adalah kunci utama tata letak presisi. Penggunaan deklarasi box-sizing: border-box; sangat efektif mencegah kerusakan dimensi tata letak akibat penambahan padding dan border.
  3. CSS Floating & Dampak Normal Flow: Properti float: left dan float: right memungkinkan penyusunan elemen multi-kolom horizontal. Namun, elemen float keluar dari aliran normal dokumen dan menyebabkan height collapse pada elemen induk.
  4. Urgensi Clearfix & Properti Clear: Penggunaan properti clear: both; serta teknik pseudo-element modern .clearfix::after mutlak dibutuhkan untuk memulihkan aliran dokumen normal serta menjaga agar elemen di bawahnya (seperti footer) tidak tumpang tindih.
  5. Manfaat HTML5 Semantics: Penggantian tag generic <div> dengan elemen semantik (<header>, <nav>, <section>, <article>, <aside>, <footer>) meningkatkan keterbacaan kode, mempermudah pemeliharaan, serta meningkatkan skor SEO dan aksesibilitas ramah pembaca layar (*screen reader*).
  6. Penyelesaian Tugas 1 dan 2: Seluruh penugasan modul berhasil direalisasikan secara sempurna. Halaman About sukses menyajikan konsep single layout profesional lengkap dengan profil, galeri proyek live portofolio (https://kasir-prefektur.gt.tc/ dan https://topupgames.gt.tc/), serta baris keterampilan. Halaman Contact berhasil menyajikan formulir interaktif lengkap beserta informasi institusi kampus.
